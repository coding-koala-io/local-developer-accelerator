# Independent implementation

This CLI is original orchestration code written from an internal functional specification.
It contains no Optimizely-derived source, binaries, assemblies, UI, logos,
documentation or recorded traffic. It does not implement vendor protocols.
The Windows helper adapts Coding Koala's own Graph service script. Tests use
synthetic releases, service records and HTTP responses. Private research folders
are excluded from the build and were not used to implement this CLI.
